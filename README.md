# 🛒 API REST — Armazém do Seu João

Bem-vindo(a) ao repositório do **Armazém do Seu João**! Este projeto consiste em uma API REST robusta desenvolvida em Node.js com TypeScript para gerenciar produtos, clientes e pedidos de um mercadinho de forma organizada. 

---

## Tecnologias Utilizadas
- **Node.js** & **TypeScript**
- **Express** (Framework web)
- **SQLite3** (Banco de dados leve e relacional)
- **Zod** (Validação de dados e tipos)
